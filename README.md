

Fonctionnalités

- Inscription, connexion et gestion utilisateur (authentification Laravel)
- Création, modification et suppression d’entrées de journal
- Chaque entrée peut être marquée comme publique ou privée
- Les utilisateurs ne peuvent modifier ou supprimer que leur propres entrées
- Les entrées publiques sont visibles par tous
- Upload d’images associées aux entrées
- Gestion des permissions avec les Policies Laravel
